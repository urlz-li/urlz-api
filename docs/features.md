# Features

## Short links

Create clean URLZ links for long URLs and manage account-linked links from a single dashboard.

## Files and photos

Upload a document or photo and receive a shareable URL without sending a large attachment. Mobile applications can capture a photo and create the link immediately.

## Password protection

Require a password before visitors can access the destination or content behind a link.

## Click analytics

Inspect link visits and useful tracking information through account endpoints and the dashboard.

## Paid access

Set a price in EUR or USD for protected content. Visitors can pay without creating an account, while creators track transactions from their account.

## URLZ Chat

Attach a private conversation to a link so the creator and recipients can discuss the shared content without installing another application.

## URLZ Request

Create a document request with a title, requested items, recipients and a deadline. Recipients can upload the requested files without creating a URLZ account.
