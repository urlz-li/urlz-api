# Code of conduct

We want the URLZ developer community to be useful, respectful and welcoming.

Participants must communicate professionally, respect privacy, avoid harassment and provide constructive technical feedback. Spam, threats, discriminatory content, credential sharing, phishing and abusive use of URLZ links are not accepted.

Report unacceptable behaviour privately through <https://urlz.li/contact/>. Repository maintainers may edit or remove content and restrict participation when necessary to protect the community.
