# Security policy

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials or exploit details in a public GitHub issue.

Report security concerns privately through <https://urlz.li/contact/>. Include:

- the affected endpoint or feature;
- steps to reproduce the issue;
- the potential impact;
- any suggested remediation;
- a safe way for the URLZ team to contact you.

Remove real user data, active tokens and API keys from reports whenever possible. The URLZ team will review the report and follow up through the contact information provided.

## Supported service

The hosted API at `https://api.urlz.li` is the supported production service. This repository contains documentation, examples and machine-readable definitions; it is not the production server source code.
